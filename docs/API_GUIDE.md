# 📘 دليل الربط البرمجي لستار موبايل (Star Mobile API v1.7.2)

مرحباً بك في بوابة المطورين الرسمية لستار موبايل. يتيح لك هذا الـ API الربط برمجياً مع خدماتنا لتنفيذ عمليات السداد والاستعلام من تطبيقاتك الخاصة بهيكلية احترافية وموحدة.

---

## 1. الإعدادات العامة (General Settings)

*   **الرابط الأساسي (Base URL):** `https://star26.vercel.app/api/external/v1`
*   **نظام الحماية (Authentication):** يجب إرسال مفتاح الربط في كل طلب داخل الـ Header.

### ● مثال لترويسة الطلب (Request Headers):
```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Accept: application/json
```

---

## 2. أكواد الحالة والأخطاء (Error Codes)

| HTTP | Code | الوصف |
| :--- | :--- | :--- |
| 200 | `SM_SUCCESS` | تمت العملية بنجاح |
| 401 | `SM_UNAUTHORIZED` | مفتاح الربط غير صحيح |
| 400 | `SM_VALIDATION_ERROR` | بيانات الطلب ناقصة (مثل نقص subscriberId) |
| 400 | `SM_INSUFFICIENT_BALANCE` | رصيدك لا يكفي |

---

## 3. فحص الرصيد الشخصي (Get Balance)

*   **المسار:** `/balance` | **الطريقة:** `GET`
*   **الوصف:** يعيد رصيدك الحالي في محفظة ستار موبايل بالريال اليمني.

---

## 4. منظومة الوادي المتطورة (Alwadi System v1.7.2)

يتبع نظام الوادي في ستار موبايل مبدأ **"الحماية المالية"**، وهو نظام من خطوتين لمنع الخسائر.

### الخطوة الأولى: الاستعلام (Lookup)
يجب الاستعلام عن الكرت أولاً للحصول على الـ `subscriberId` الإلزامي.

**● الطلب (Request):**
```json
// POST /alwadi
{
  "action": "lookup",
  "number": "رقم_الكرت"
}
```

**● الرد (Response):** سيعيد الحقل `subscriberId`.

---

### الخطوة الثانية: التجديد الفعلي (Renew)
يتم تنفيذ التجديد مع خصم **2.5%** من السعر الرسمي تلقائياً. **يمنع النظام التجديد بدون المعرف.**

**● الأسعار المعتمدة للربط (خصم 2.5%):**
| الباقة | السعر الرسمي | سعر الربط (API) |
| :--- | :--- | :--- |
| شهرين (1) | 3,000 ر.ي | **2,925 ر.ي** |
| 4 أشهر (3) | 6,000 ر.ي | **5,850 ر.ي** |
| 6 أشهر (7) | 9,000 ر.ي | **8,775 ر.ي** |
| سنة (9) | 15,000 ر.ي | **14,625 ر.ي** |

**● الطلب (Request):**
```json
// POST /alwadi
{
  "action": "renew",
  "number": "رقم_الكرت",
  "packageId": "1", 
  "subscriberId": "المعرف_المستخرج_من_الاستعلام" 
}
```

---

### الخطوة الاختيارية: وضع التجربة (Test Renew)
يستخدم لتجربة الربط والخصم والسجل دون تفعيل كرت حقيقي في المنظومة. سيتم خصم الرصيد في السجل وتسجيل العملية ثم إتاحته فوراً.

**● الطلب (Request):**
```json
{
  "action": "test_renew",
  "number": "رقم_الكرت",
  "packageId": "1"
}
```

---

## 5. ملاحظات تقنية هامة

*   **الخصم الآلي:** يتم خصم القيمة المخفضة (2.5% أقل) تلقائياً من رصيد العميل المربوط بالمفتاح.
*   **الإشعارات:** عند التجديد عبر API، يتم تسجيل العملية في سجل العميل فوراً.
*   **الحماية:** أي طلب تجديد (`renew`) بدون `subscriberId` سيتم رفضه فوراً من النظام لحمايتك.
