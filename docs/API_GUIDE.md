# 📘 دليل الربط البرمجي لستار موبايل (Star Mobile API v1.7.5)

مرحباً بك في بوابة المطورين الرسمية لستار موبايل. يتيح لك هذا الـ API الربط برمجياً مع خدماتنا لتنفيذ عمليات السداد والاستعلام من تطبيقاتك الخاصة بهيكلية احترافية ومحماية مالية فائقة.

---

## 1. الإعدادات العامة (General Settings)

*   **الرابط الأساسي (Base URL):** `https://star26.vercel.app/api/external/v1`
*   **نظام الحماية (Authentication):** يجب إرسال مفتاح الربط في كل طلب داخل الـ Header.

### ● مثال لترويسة الطلب (Request Headers):
```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Accept: application/json
```

---

## 2. منظومة الوادي (Alwadi System v1.7.5)

تتبع منظومة الوادي نظام الأمان المزدوج (Double Check)؛ حيث يجب الاستعلام أولاً ثم إرسال المعرف المطابق في طلب التجديد.

### الخطوة الأولى: الاستعلام (Lookup)
تستخدم للتأكد من وجود الكرت والحصول على **معرف المشترك (subscriberId)** الإلزامي.

**● الطلب (Request):**
```json
// POST /alwadi
{
  "action": "lookup",
  "number": "رقم_الكرت"
}
```

---

### الخطوة الثانية: التجديد الفعلي (Renew)
يتم تنفيذ التجديد مع خصم **2.5%** تلقائياً من رصيدك في ستار موبايل.

**● القواعد الذكية:**
1. يجب إرسال `subscriberId` صحيح يخص رقم الكرت.
2. يجب أن تكون الباقة من القائمة المعتمدة (1, 3, 7, 9).

**● الأسعار المعتمدة للربط (خصم 2.5%):**
| الباقة | السعر الرسمي | سعر الربط (API) |
| :--- | :--- | :--- |
| شهرين (1) | 3,000 ر.ي | **2,925 ر.ي** |
| 4 أشهر (3) | 6,000 ر.ي | **5,850 ر.ي** |
| 6 أشهر (7) | 9,000 ر.ي | **8,775 ر.ي** |
| سنة (9) | 15,000 ر.ي | **14,625 ر.ي** |

**● الطلب (Request):**
```json
{
  "action": "renew",
  "number": "15514",
  "packageId": "1", 
  "subscriberId": 79359 // إلزامي ومطابق لرقم الكرت
}
```

---

### وضع التجربة (Test Renew)
يستخدم لتجربة الربط البرمجي والسجلات دون تفعيل كرت حقيقي. سيتم خصم الرصيد ثم استرجاعه فوراً للتأكد من نجاح الخصم والسجل.

**● الطلب (Request):**
```json
{
  "action": "test_renew",
  "number": "رقم_الكرت",
  "packageId": "1",
  "subscriberId": 79359
}
```

## 3. أكواد الحالة والأخطاء (العربية)

| HTTP | Code | رسالة الخطأ | الوصف |
| :--- | :--- | :--- | :--- |
| 200 | `SM_SUCCESS` | تمت العملية بنجاح | العملية اكتملت تماماً |
| 400 | `SM_ID_MISMATCH` | رقم المعرف لا يطابق رقم الكرت | المعرف المرسل لا ينتمي لهذا الكرت |
| 400 | `SM_VALIDATION_ERROR` | الباقة غير موجودة | رقم الباقة المرسل غير صحيح |
| 400 | `SM_VALIDATION_ERROR` | رقم معرف المشترك مطلوب | تم نسيان حقل subscriberId |
| 400 | `SM_INSUFFICIENT_BALANCE` | رصيدك الحالي لا يكفي | رصيد حسابك في ستار موبايل منخفض |
