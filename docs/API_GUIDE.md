# 📘 دليل الربط البرمجي لستار موبايل (Star Mobile API v1.7.5)

مرحباً بك في بوابة المطورين الرسمية لستار موبايل. يتيح لك هذا الـ API الربط برمجياً مع خدماتنا لتنفيذ عمليات السداد والاستعلام من تطبيقاتك الخاصة بهيكلية احترافية ومحماية مالية فائقة.

---

## 1. الإعدادات العامة (General Settings)

*   **الرابط الأساسي (Base URL):** `https://star26.vercel.app/api/external/v1`
*   **نظام الحماية (Authentication):** يجب إرسال مفتاح الربط في كل طلب داخل الـ Header.

### ● مثال لترويسة الطلب (Request Headers):
```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Accept: application/json
```

---

## 2. منظومة الوادي (Alwadi System v1.7.5)

تتبع منظومة الوادي نظام الأمان المزدوج (Double Check)؛ حيث يجب الاستعلام أولاً ثم إرسال المعرف المطابق في طلب التجديد.

### الخطوة الأولى: الاستعلام (Lookup)
تستخدم للتأكد من وجود الكرت والحصول على **معرف المشترك (subscriberId)** الإلزامي.

**● الطلب (Request):**
```json
// POST /alwadi
{
  "action": "lookup",
  "number": "رقم_الكرت"
}
```

---

### الخطوة الثانية: التجديد الفعلي (Renew)
يتم تنفيذ التجديد مع خصم **2.5%** تلقائياً من رصيدك في ستار موبايل.

**● القواعد الذكية:**
1. يجب إرسال `subscriberId` صحيح يخص رقم الكرت.
2. يجب أن تكون الباقة من القائمة المعتمدة (1, 3, 7, 9).

**● الأسعار المعتمدة للربط (خصم 2.5%):**
| الباقة | السعر الرسمي | سعر الربط (API) |
| :--- | :--- | :--- |
| شهرين (1) | 3,000 ر.ي | **2,925 ر.ي** |
| 4 أشهر (3) | 6,000 ر.ي | **5,850 ر.ي** |
| 6 أشهر (7) | 9,000 ر.ي | **8,775 ر.ي** |
| سنة (9) | 15,000 ر.ي | **14,625 ر.ي** |

**● الطلب (Request):**
```json
{
  "action": "renew",
  "number": "15514",
  "packageId": "1", 
  "subscriberId": 79359 // إلزامي ومطابق لرقم الكرت
}
```

---

### وضع التجربة (Test Renew)
يستخدم لتجربة الربط البرمجي والسجلات دون تفعيل كرت حقيقي. سيتم خصم الرصيد ثم استرجاعه فوراً للتأكد من نجاح الخصم والسجل.

**● الطلب (Request):**
```json
{
  "action": "test_renew",
  "number": "رقم_الكرت",
  "packageId": "1",
  "subscriberId": 79359
}
```

## 3. سداد باقات شركة يو (YOU Packages API)

تتيح لك نقطة النهاية الموحدة لسداد الاتصالات `/pay` تفعيل باقات شركة يو (YOU) برمجياً، حيث يتم خصم المبلغ المحدد للباقة بدقة، وتسجيل العملية في سجل الحساب كـ **باقة (وليس سداد رصيد)** مع اسم الباقة ورقم المستلم.

### ● نقطة النهاية (Endpoint):
* **الرابط:** `POST https://star26.vercel.app/api/external/v1/pay`
* **الترويسة (Headers):**
  ```http
  Authorization: Bearer YOUR_API_KEY
  Content-Type: application/json
  Accept: application/json
  ```

---

### ● شكل الطلب البرمجي (Request Body):
لطلب تفعيل باقة يو، أرسل كود الباقة إما في حقل `packageid` أو `num`:

```json
{
  "mobile": "73XXXXXXX",
  "service": "you",
  "action": "billoffer",
  "packageid": "Mix_4GB_4G_PRE"
}
```

> **ملاحظة:** يمكنك أيضاً إرسال الطلب مع تحديد `action: "offer"` أو تمرير الكود في حقل `num`، وسيتعرف النظام عليها تلقائياً كباقة ويسجلها في السجل باسم الباقة الرسمي.

### ● تسجيل المعاملة في سجل العمليات (Transaction History):
* عند إرسال باقة، تُسجل فوراً في سجل العميل كـ:
  * **نوع العملية (transactionType):** `يو - باقة السعر الموحد 4 جيجا فورجي`
  * **الملاحظات (notes):** `تفعيل باقة السعر الموحد 4 جيجا فورجي للرقم: 73XXXXXXX`
  * **التصنيف (serviceCategory):** `يو`
  * **الجاهزية (readiness):** `جاهزة` أو `قيد الانتظار`
* **لا تُسجل العملية أبداً كـ "سداد رصيد"** عند إرسال باقة.

## 4. متابعة العمليات المتأخرة وتحديث الحالة لكافة شبكات الاتصالات (Status Sync & Webhook)

في قطاع الاتصالات في اليمن (يمن موبايل، يو، سبأفون، واي، يمن فورجي، عدن نت، الهاتف الثابت والإنترنت)، قد تتأخر استجابة نظام المزود لبعض العمليات؛ في هذه الحالة يرجع لك الـ API رد بحالة `SM_PENDING` (قيد الانتظار) مع رقم مرجع العملية `transactionId`.

لتحديث حالة العملية لعملائك بمجرد اكتمالها، يوفر لك النظام **طريقتين احترافيتين**:

---

### الطريقة الأولى: الاستعلام المباشر مع الفحص الحي (Live Status Query)
يمكن لنظامك الاستعلام الدوري (Polling) عن حالة العملية باستخدام رقم `transactionId`.
> **ميزة الفحص الحي:** عند إرسال طلب استعلام وكانت العملية لا تزال "قيد الانتظار"، يقوم سيرفرنا فوراً بعمل **فحص ومزامنة حية (Live Sync)** مع مزود الاتصالات في نفس اللحظة؛ فإذا اكتملت العملية تتحول تلقائياً إلى `جاهزة`، وإذا رُفضت تتحول إلى `فاشلة` ويُعاد الرصيد فوراً لحسابك، ويصلك الرد النهائي المحدث في نفس الثانية!

#### ● خيارات الاستعلام المتاحة:

##### 1. عبر نقطة نهاية العمليات (GET /transactions):
```http
GET https://star26.vercel.app/api/external/v1/transactions?transid=173000000000
Authorization: Bearer YOUR_API_KEY
```

##### 2. أو عبر الـ Body (POST /transactions):
```http
POST https://star26.vercel.app/api/external/v1/transactions
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "transid": "173000000000"
}
```

##### 3. أو مباشرة عبر نقطة السداد (POST /pay):
```http
POST https://star26.vercel.app/api/external/v1/pay
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "action": "status",
  "transid": "173000000000"
}
```

#### ● نموذج الرد (Response):
```json
{
  "success": true,
  "code": "OK",
  "data": {
    "transid": "173000000000",
    "amount": 2904,
    "currency": "YER",
    "status": "success", // أو "failed" أو "pending"
    "readiness": "جاهزة", // أو "فاشلة" أو "قيد الانتظار"
    "transactionType": "يو - باقة السعر الموحد 4 جيجا فورجي",
    "recipientPhoneNumber": "73XXXXXXX",
    "providerMessage": "تم تنفيذ العملية بنجاح",
    "refunded": false,
    "createdAt": "2026-10-26T15:00:00.000Z",
    "completedAt": "2026-10-26T15:02:15.000Z"
  }
}
```

---

### الطريقة الثانية: إشعار الـ Webhook التلقائي (Callback Push)
إذا كنت لا ترغب بالاستعلام الدوري، يمكنك تزويدنا برابط الـ Webhook الخاص بسيرفرك في حقل `backurl` أثناء إرسال طلب السداد:

```json
{
  "mobile": "73XXXXXXX",
  "service": "you",
  "action": "billoffer",
  "packageid": "Mix_4GB_4G_PRE",
  "backurl": "https://your-domain.com/api/telecom/callback"
}
```

* بمجرد أن يكتمل تنفيذ العملية أو يتم رفضها لدى مزود الاتصالات (سواء بعد 30 ثانية أو 5 دقائق)، سيقوم سيرفر ستار موبايل بإرسال طلب `POST` فوري وتلقائي إلى رابطك (`backurl`) بالبيانات التالية:

```json
{
  "transid": "173000000000",
  "status": "success", // أو "failed"
  "readiness": "جاهزة", // أو "فاشلة"
  "amount": 2904,
  "mobile": "73XXXXXXX",
  "service": "يو - باقة السعر الموحد 4 جيجا فورجي",
  "message": "تم تنفيذ العملية بنجاح"
}
```

## 5. أكواد الحالة والأخطاء (العربية)

| HTTP | Code | رسالة الخطأ | الوصف |
| :--- | :--- | :--- | :--- |
| 200 | `SM_SUCCESS` | تم تنفيذ العملية بنجاح | العملية اكتملت بنجاح وتغيرت الجاهزية إلى جاهزة |
| 200 | `SM_PENDING` | تم إرسال الطلب وهو قيد المعالجة (قيد الانتظار) | الطلب أرسل للمزود والعملية معلقة حالياً |
| 400 | `SM_VALIDATION_ERROR` | أخطاء التحقق من المدخلات | نقص حقول أو طول رقم غير مطابق |
| 400 | `SM_INSUFFICIENT_BALANCE` | رصيد حسابك غير كافٍ لتنفيذ هذه العملية | الرصيد الحالي أقل من تكلفة الخدمة |
| 400 | `SM_PROVIDER_ERROR` | رسالة سبب الرفض من المزود | تم رفض العملية وإرجاع المبلغ لحسابك فوراً |
| 401 | `SM_UNAUTHORIZED` | Missing or invalid API key | مفتاح الربط مفقود أو غير صالح |
| 403 | `SM_FORBIDDEN` | Invalid API Key | مفتاح الربط غير موجود في النظام |
| 404 | `SM_NOT_FOUND` | العملية غير موجودة | رقم transid المستعلم عنه غير صحيح |
