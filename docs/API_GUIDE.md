# 📘 دليل الربط البرمجي لستار موبايل (Star Mobile API v1.7.5)

مرحباً بك في بوابة المطورين الرسمية لستار موبايل. يتيح لك هذا الـ API الربط برمجياً مع خدماتنا لتنفيذ عمليات السداد والاستعلام من تطبيقاتك الخاصة بهيكلية احترافية وموحدة.

---

## 1. الإعدادات العامة (General Settings)

*   **الرابط الأساسي (Base URL):** `https://star26.vercel.app/api/external/v1`
*   **نظام الحماية (Authentication):** يجب إرسال مفتاح الربط في كل طلب داخل الـ Header.

### ● مثال لترويسة الطلب (Request Headers):
```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Accept: application/json
```

---

## 2. أكواد الحالة والأخطاء (Error Codes)

| HTTP | Code | الوصف |
| :--- | :--- | :--- |
| 200 | `SM_SUCCESS` | تمت العملية بنجاح |
| 401 | `SM_UNAUTHORIZED` | مفتاح الربط غير صحيح |
| 400 | `SM_VALIDATION_ERROR` | بيانات الطلب ناقصة أو الـ subscriberId مفقود |
| 400 | `SM_INSUFFICIENT_BALANCE` | رصيدك لا يكفي |

---

## 3. فحص الرصيد الشخصي (Get Balance)

*   **المسار:** `/balance` | **الطريقة:** `GET`
*   **الوصف:** يعيد رصيدك الحالي بالريال اليمني.

---

## 4. منظومة الوادي (Alwadi System v1.7.5)

تتبع منظومة الوادي نظام الأمان المزدوج؛ حيث يجب الاستعلام أولاً ثم إرسال المعرف في طلب التجديد.

### الخطوة الأولى: الاستعلام (Lookup)
يستخدم للتأكد من وجود الكرت والحصول على **معرف المشترك (subscriberId)** الإلزامي.

**● الطلب (Request):**
```json
// POST /alwadi
{
  "action": "lookup",
  "number": "رقم_الكرت"
}
```

---

### الخطوة الثانية: التجديد الفعلي (Renew)
يتم تنفيذ التجديد مع خصم **2.5%** تلقائياً. **يمنع النظام التجديد بدون subscriberId و number و packageId.**

**● الأسعار المعتمدة للربط (خصم 2.5%):**
| الباقة | السعر الرسمي | سعر الربط (API) |
| :--- | :--- | :--- |
| شهرين (1) | 3,000 ر.ي | **2,925 ر.ي** |
| 4 أشهر (3) | 6,000 ر.ي | **5,850 ر.ي** |
| 6 أشهر (7) | 9,000 ر.ي | **8,775 ر.ي** |
| سنة (9) | 15,000 ر.ي | **14,625 ر.ي** |

**● الطلب (Request):**
```json
{
  "action": "renew",
  "number": "رقم_الكرت",
  "packageId": "1", 
  "subscriberId": 79359 // إلزامي تماماً
}
```

---

### وضع التجربة (Test Renew)
يستخدم لتجربة الربط والسجل دون تفعيل كرت حقيقي. سيتم خصم الرصيد ثم استرجاعه فوراً. يتطلب أيضاً وجود `subscriberId`.

**● الطلب (Request):**
```json
{
  "action": "test_renew",
  "number": "رقم_الكرت",
  "packageId": "1",
  "subscriberId": 79359
}
```

---

## 5. ملاحظات تقنية هامة

*   **إلزامية المعرف:** أي طلب تجديد لا يحتوي على `subscriberId` سيتم رفضه برسالة: "رقم معرف المشترك مطلوب لتنفيذ التجديد".
*   **الخصم الآلي:** يتم خصم القيمة المخفضة (2.5% أقل) تلقائياً من رصيدك في ستار موبايل.
*   **الحماية:** تم تصميم هذا النظام لمنع العمليات العشوائية التي قد تسبب خسائر مالية للموزع.
